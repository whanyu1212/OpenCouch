# Voice

Voice support is temporarily removed while the text agent migration and
runtime cleanup settle.

The previous LiveKit worker under `apps/backend/agent/voice/`, the
`scripts/voice_agent.sh` wrapper, and the `/api/voice/livekit/*` routes
have been removed. The next voice implementation should be designed
from scratch against the post-migration text runtime instead of preserving
compatibility with the legacy LiveKit path.
