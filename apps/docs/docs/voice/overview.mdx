# Voice

Voice support uses OpenAI Realtime speech-to-speech sessions from the
web app.

The browser connects to OpenAI Realtime over WebRTC. The FastAPI backend
creates the client secret, injects OpenCouch instructions and memory
context, exposes the same app-owned tools as the text runtime, records
finalized turns, and runs session finalization for persistent mode.

The production web route is `/voice`. The lower-level dogfood route
`/voice/realtime-dev` remains available for inspecting raw Realtime
events without the full product shell.
