# Prompt Assembly

Not one giant string. Every system prompt is assembled in discrete
layers — each with a clear source, defined scope, and explicit
separation of concerns.

## Layer architecture

Lower layers are always present. Upper layers are selected at
runtime by the graph.

## How the layers combine

| Layer | Question it answers | Source | Per turn? |
|---|---|---|---|
| **Core** | Who is this system? What are the hard rules? | `soul.md`, `identity.md`, `policy/boundaries.md`, `policy/privacy.md` (collected as `CORE_SOURCES` in `prompts/shared.py`) | Never changes |
| **Mode** | What response shape is this turn? | `response_modes/*.md` — one file per mode (7 files: support, reflection, psychoeducation, guided_exercise, closing, crisis_response, safety_check) | Selected by dispatcher / crisis gate |
| **Modality** | What therapy framework overlay? | `modalities/*.md` — 8 files: motivational_interviewing, cbt, cbt_arc, act, dbt_skills, grief_support, interpersonal_therapy, pfa | Per turn, picked by dispatcher |
| **Instructions** | How should it respond on this turn specifically? | Mode-specific blocks in `agent/therapeutic/prompts.py` and `agent/prompts/crisis.py` | Per mode |
| **Working memory** | What does it know about the user? | Semantic + episodic entries from `load_memory_node` | Re-retrieved each turn |
| **Procedural rules** | What style rules apply? | Rules from `ProceduralProfile`, injected as suffix | Loaded each turn |

:::info Two kinds of injected context
**Working memory** shapes the agent's *awareness* — "Previously
noted: user has a sister named Sarah." **Procedural rules** shape
its *behavior* — "this user prefers shorter responses." Rules are
always applied regardless of the proactive recall toggle.
:::

The crisis branch composes a tighter prompt: `CORE_SOURCES` +
`response_modes/crisis_response.md` (and `policy/crisis.md` for the
classifier prompt) + recent history. Memory layers are skipped on
crisis turns by design.

The `safety_check` mode is the response shape used when the crisis
classifier returns level 1 (ambiguous distress, `needs_clarification`)
— a one-question safety probe inside the therapeutic branch rather
than a full crisis response.

## Why layers

| Property | How layers enforce it |
|---|---|
| Safety policy can't be overwritten | Core layer (including `policy/boundaries.md` + `policy/privacy.md`) is always first; no style/approach can weaken it |
| Mode knowledge is reviewable | Each mode's knowledge is a standalone `.md` in `agent/prompts/sources/response_modes/` |
| Procedural rules can't be overridden | Injected last as system prompt suffix; safety-conflict rules ("skip the safety check") are dropped by the procedural extractor |
| Each layer has a clear owner | `agent/prompts/sources/` for content, `agent/therapeutic/prompts.py` and `agent/prompts/crisis.py` for assembly |

## Implementation

| File | What it does |
|---|---|
| `agent/prompts/__init__.py` | Re-exports `compose_sources`, `CORE_SOURCES`, crisis prompt builders |
| `agent/prompts/shared.py` | `CORE_SOURCES` tuple, `load_prompt_source()`, `compose_sources()`, `format_recent_history()` |
| `agent/prompts/crisis.py` | Crisis classifier + crisis response prompt builders |
| `agent/therapeutic/prompts.py` | `_knowledge_for_mode()`, per-mode instruction blocks, `build_*_system_prompt()` for each therapeutic mode |
| `agent/prompts/sources/soul.md` | Identity, voice, tone, pacing, directness |
| `agent/prompts/sources/identity.md` | Product boundaries and positioning |
| `agent/prompts/sources/policy/` | Safety + privacy + crisis policy (3 files) |
| `agent/prompts/sources/response_modes/` | One file per response mode (7 files) |
| `agent/prompts/sources/modalities/` | 8 modality knowledge files, dynamically loaded per turn |
| `agent/prompts/sources/session_stages.md` | Stage-aware response guidance (not yet wired into the graph) |
| `agent/prompts/sources/cross_session_continuity.md` | First-turn catch-up framing |
| `agent/nodes/load_memory.py` | Populates `working_memory` and `procedural_profile.procedural_rules` |
