# Scenarios

Eight conversations showing how the agent routes, responds, and
adapts turn by turn. Each turn shows the actual chat, the graph
routing path, and why the dispatcher made its decision.

All mode names match the shipped graph nodes. Routing traces show
the actual node sequence the turn would follow through the pipeline.
