OpenCouch LiveKit Room Test

Join a real LiveKit room from the browser, publish your microphone, and listen to the agent's audio. Use this with either connect --room ... for a specific room or with a running worker that auto-dispatches opencouch-voice from the token endpoint.

Typical flow for a specific room: 1. Run uv run python -m voice.livekit.agent connect --room my-test-room 2. Start the backend server 3. Open /api/voice/livekit/test?room=my-test-room 4. Leave agent dispatch unchecked, click Connect, and allow microphone access
