# 5-4-3-2-1 Grounding

## Use when

Use when the user feels anxious, panicky, overwhelmed, dissociated, disconnected from the present moment, or asks to be grounded.

## Do not use when

- The user is in acute crisis and needs crisis support.
- The user asks for factual lookup, memory-control behavior, or another non-exercise task.
- The application runtime selected a different guided exercise.

## Operating boundaries

- Follow the runtime-selected step exactly.
- Do not skip, reorder, or add exercise steps.
- Keep each reply brief and paced for one exercise turn.
- Rephrase naturally without changing the task.
- Stop if the user wants to exit.

## Steps

1. Invite the user to name things they can see.
2. Invite the user to name things they can hear.
3. Invite the user to name things they can feel.
4. Invite the user to name things they can smell.
5. Invite the user to name one thing they can taste, or to notice one slow breath.
