# Box Breathing

## Use when

Use when the user wants to slow down, regulate breathing, settle body activation, or work with stress and racing-heart sensations.

## Do not use when

- The user is in acute crisis and needs crisis support.
- Breath-focused exercises appear distressing or unwanted.
- The user asks for factual lookup, memory-control behavior, or another non-exercise task.
- The application runtime selected a different guided exercise.

## Operating boundaries

- Follow the runtime-selected step exactly.
- Do not skip, reorder, or add breathing steps.
- Keep pacing gentle and non-forceful.
- Remind the user not to strain.
- Stop if the user wants to exit.

## Steps

1. Invite the user to breathe in gently for a count of four.
2. Invite the user to hold the breath softly for a count of four.
3. Invite the user to breathe out slowly for a count of four.
4. Invite the user to hold after exhaling for a count of four.
