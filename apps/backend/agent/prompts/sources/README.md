# Knowledge

Root-level knowledge sources for OpenCouch.

This directory is for curated reference content that supports:
- prompt composition
- policy and boundary definitions
- response-mode design
- modality overlays such as PFA, MI, CBT, IPT, ACT, and DBT-informed skills
- guided exercise templates
- crisis resource lookup
- structured retrieval pipelines

Keep this material:
- reviewed
- attributable
- separated from runtime code

Recommended structure:
- `soul.md` for core identity and values
- `identity.md` for external presentation
- `policy/` for hard rules and boundaries
- `response_modes/` for workflow-specific guidance
- `modalities/` for intervention overlays
- `session_stages.md` for stage-aware response guidance across longer conversations
